# AI時短ラボ v2 — 承認制の静的ブログ

## 状態
ローカルのブログ生成・承認ゲート・広告リンク表示・GitHub Pagesデプロイ用ワークフローを実装。**公開、アカウント開設、ASP審査、動画生成・投稿、AI API連携、収益取得は未実施。** 記事は未承認で、初期状態では公開されません。

## まずローカルで確認
Python 3.10以降を用意し、このフォルダで `python build.py` を実行。`site/index.html` をブラウザで開きます。初期状態は記事0件です。

## 記事の承認手順
1. `content/weekly-planner.json` の文章を実際に操作・検証し、独自の画面や検証結果を加えます。
2. 事実確認後に `verified:true`、権利確認後に `rights_checked:true`、本人が公開を承認したら `approved:true` に変更します。
3. `publish_at` にタイムゾーン付きの公開予定日時を指定。時刻到来後のビルドで記事を出力します。**自動時刻実行は未設定**です。
4. ASP承認後のみ `config.json` の `affiliate_links` に実際のHTTPS広告URLを登録し、記事の `affiliate_key` にそのキーを設定。キーに対応するURLがない場合、記事は公開されません。
5. 公開を停止する場合はルートに `STOP` というファイルを作成してビルドします。既存公開サイトから消すには変更をGitHubへ反映する必要があります。

## GitHub Pagesへの公開（ユーザーによるアカウント開設と操作が必要）
1. https://github.com/signup から本人がアカウントを作成し、メールを認証します。
2. 公開リポジトリ `ai-jitan-lab` を新規作成し、**個人情報やAPIキーを除いた**このフォルダのファイルをアップロードします。`main` ブランチを使います。
3. リポジトリ Settings → Pages → Build and deployment → Source で **GitHub Actions** を選択します。
4. Actions の `Publish approved pages` を手動実行します。初期状態では記事0件のトップページだけが公開されます。
5. Pagesに表示される実際のURLを確認。独自ドメインは後から設定可能で、初期段階では不要です。
6. 運営者情報、問い合わせ先、プライバシーポリシーを実際の情報に置き換えてからASP審査に申し込みます。現状のabout.htmlは仮文です。
